# Triangle Inequality Visualizer

An interactive, single-page explorer for triangle problems where side lengths are given in terms of `x`.

- Enter vertex names, side expressions (e.g. `12 + x`, `20 - x`, `3(x - 1)`), and an optional angle order.
- Drag the slider to see the triangle (with compass arcs) for each value of `x`.
- Live checks for positive sides, angle order → side order, and the Triangle Inequality.
- A number line and solution table show the allowed values of `x`.
- "Hide the answer" mode for class discussion.

## Usage

Open `index.html` in any browser. No build step or server needed.
